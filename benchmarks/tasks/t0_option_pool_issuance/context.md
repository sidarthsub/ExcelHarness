# User context

You are a founder preparing a board deck. You want the option pool math
to follow the standard "pre-money inclusion" convention used by VCs: the
option pool expansion dilutes **only the existing shareholders**, not the
new investors.

## Defaults you would pick

- Pre-money inclusion (only existing holders absorb the pool dilution).
- "Existing unallocated" counts toward the new pool target (net top-up,
  not a gross reset).
- Decimal / share-fraction values are acceptable — don't round the answer.

## Things you do NOT know or care about

- Cell formatting, number precision beyond a handful of decimals.
- Whether formulas use direct cell refs or named ranges — either is fine.
- Whether intermediate cells show up alongside the answer — you just want
  the right number in B10.
