# Layout conventions

## Sources & Uses sheet
- Sheet "Sources and Uses"
- Row 1: title (bold)
- Two sections: Sources (rows 3-7) and Uses (rows 9-12)
- Row 14: Check (sources = uses)

## Operating Model
- Sheet "Operating Model"
- Columns: A = label, B-F = Y1..Y5 (one column per year)
- Rows: Revenue, EBITDA, D&A, EBIT, Interest (TLB + Mezz), Pre-tax, Tax, Net income, Capex, FCF pre-debt, Mandatory amort, Cash sweep, TLB end balance, Mezz end balance

## Returns sheet
- Sheet "Returns"
- Entry equity | Exit EV | Exit EBITDA | Net debt at exit | Exit equity | MOIC | IRR
